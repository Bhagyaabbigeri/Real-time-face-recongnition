# New Face Recognition Project

This project implements a real-time face recognition system using Python and OpenCV. It utilizes Haar Cascades for face detection and the LBPH (Local Binary Patterns Histograms) algorithm for face recognition.

## Project Structure

- `dataset/`: Contains subdirectories for each person, named with their unique ID (e.g., `0`, `1`, `2`, ...). Each subdirectory should contain multiple images of that person's face.
- `trainmodel.py`: Script to process the images in the `dataset` folder and train the face recognition model.
- `facemodel.yml`: The trained model file generated by `trainmodel.py`.
- `camdemo.py`: Real-time face recognition script that uses your computer's webcam.
- `verifyface (1).py`: Script for verifying or testing recognition on specific images.
- `haarcascade_frontalface_default.xml`: Pre-trained Haar Cascade model for detecting frontal faces.
- `import cv2.py`, `import test.py`, `import text2.py`: Utility or experimental scripts.

## Prerequisites

Ensure you have Python installed, then install the required libraries:

```bash
pip install opencv-contrib-python
```

*Note: `opencv-contrib-python` is required for the face recognition modules.*

## Usage

### 1. Prepare the Dataset
Organize your training images in the `dataset/` directory. Each person should have their own folder named with a numeric ID.
Example:
```
dataset/
├── 0/
│   ├── image1.jpg
│   ├── image2.jpg
├── 1/
│   ├── image1.jpg
│   ├── image2.jpg
```

### 2. Train the Model
Run the training script to generate the `facemodel.yml` file:

```bash
python trainmodel.py
```

### 3. Run Real-Time Recognition
Start the webcam-based recognition:

```bash
python camdemo.py
```

## How It Works

1. **Face Detection**: The system uses a Haar Cascade classifier (`haarcascade_frontalface_default.xml`) to locate faces in each frame of the video stream.
2. **Recognition**: Once a face is detected, it is cropped, converted to grayscale, and passed to the LBPH recognizer.
3. **Prediction**: The recognizer compares the detected face against the trained data in `facemodel.yml` and returns the ID of the person with a confidence score.

## Troubleshooting

- **Camera not opening**: Ensure no other application is using the webcam.
- **Low Accuracy**: Ensure you have enough varied images (lighting, angles) in the `dataset` for each person.
- **Module Error**: Make sure you installed `opencv-contrib-python` and not just `opencv-python`.
